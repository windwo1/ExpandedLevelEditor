# GW2 Level Editor

A modified version of the Level Editor plugin for 1.0.7 for both PvZ GW2 & PvZ GW1. It will let you export levels. Exports meshes, textures, terrain, terrain layers and vector paramaters.

Python scripts to import the levels to blender:
